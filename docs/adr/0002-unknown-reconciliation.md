# Offline UNKNOWN reconciliation

Status: accepted for development main.

Reconcile existing Spuro session JSON without rescanning repositories or invoking
providers. Preserve per-intent states. Group exact payload sightings within a
host-qualified provider thread, retain every member, and never merge distinct
threads by prose similarity. Rank UNKNOWN/promise candidates by useful evidence:
scoped cached Git predicates, explicit later links/decisions, and separately
labelled fuzzy later-intent suggestions. A cwd association remains contextual.

Cached matches prove only their narrow predicate at the original observation.
Fuzzy similarity, path mentions, remote names, tracker closure, and task-board
prose do not establish completion, requirement, authorship, or preservation.
Missing chronology, scope, criteria, and later coverage produce explicit gaps.

Acceptance: synthetic duplicate/schema sightings collapse with member provenance;
foreign hosts and ambiguous repositories do not cross-match; later linked user
cancellation is visible; similar later prose remains a suggestion; cached Git
matches do not change lifecycle states; text-free reports omit excerpts; offline
CLI performs no Git/provider calls and protects input/repository output paths.
Private Windows candidate schemas are not guessed; their artifacts are unavailable
from the current implementation host. No Ubuntu WSL access is part of this work.
